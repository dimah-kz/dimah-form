### Improve fill template, typed UI meta, and session errors

`FormView` infers `layout` (`fill` / `steps` / `review`). Wizard Next validates the current step; Enter advances when `FormSteps` wraps `FormRoot`. Field `meta` is a typed `FieldUiMeta` bag (`width`, `help`, `prefix` / `suffix`, `stepTitle`, `unsetOnOff`, …). Boolean off writes `false` unless `unsetOnOff`. Session state exposes `errorCode` and `autosave` so the UI can localize request errors and hide Save draft during autosave.
