dimah-form does not ship sessions. Put auth in `guard`.
Set `respondentId` in `onStart`. Send email and webhooks from `after*` — the row is already stored.

## guard

`guard` runs before the handler. A thrown `APIError` is the response.

```ts title="lib/form.ts"
import {
  APIError,
  FORM_ERROR_CODES,
  dimahForm,
  memoryAdapter,
} from "@dimah-form/server";
import { forms } from "@/lib/forms";

const adminOperations = [
  "saveForm",
  "deleteForm",
  "listResponses",
  "getResponseScores",
  "getDatasetPage",
  "getDatasetCodebook",
  "getLiveCodebook",
  "getFormInsights",
  "getFormCrosstab",
];

export const form = dimahForm({
  database: memoryAdapter(),
  forms,
  guard: async ({ request, operation, responseId, getResponse }) => {
    const session = await getSession(request);
    if (!session) {
      throw APIError.from("UNAUTHORIZED", FORM_ERROR_CODES.UNAUTHORIZED);
    }

    if (adminOperations.includes(operation) && session.user.role !== "admin") {
      throw APIError.from("FORBIDDEN", FORM_ERROR_CODES.FORBIDDEN);
    }

    if (!responseId) return;

    const record = await getResponse(responseId);
    if (record?.respondentId && record.respondentId !== session.user.id) {
      throw APIError.from("FORBIDDEN", FORM_ERROR_CODES.FORBIDDEN);
    }
  },
});
```

| Argument                |                                                              |
| ----------------------- | ------------------------------------------------------------ |
| `request`               | Incoming `Request`                                           |
| `operation`             | `"startResponse"`, `"submitResponse"`, a plugin operation, … |
| `formId` / `responseId` | Present when the payload has them                            |
| `getResponse(id)`       | Store read. Does not re-enter `guard`                        |
| `getForm(idOrSlug)`     | Code catalog first, then `database.getForm`                  |

`getResponse` and `getForm` are for authorization. Do not write from `guard`.

## Client credentials

```ts title="lib/form-client.ts"
"use client";

import { createFormClient } from "@dimah-form/react";
import type { Form } from "@/lib/form";

export const formClient = createFormClient<Form>({
  basePath: "/api/form",
  credentials: "include",
  headers: async () => {
    const token = await getClientToken();
    return token ? { Authorization: `Bearer ${token}` } : {};
  },
});
```

`form.api` does not see browser cookies unless you pass `headers`.

## Hooks

`on*` runs after validation and before the write. Mutate `response` or `form` there. A throw aborts the write.
`after*` runs after a successful write.

```ts title="lib/form.ts"
export const form = dimahForm({
  database: memoryAdapter(),
  hooks: {
    onStart: async ({ request, response }) => {
      const session = await getSession(request);
      if (session) response.respondentId = session.user.id;
    },
    afterSubmit: async ({ response }) => {
      await sendMail({
        subject: `Response ${response.id}`,
        formId: response.formId,
      });
    },
  },
});
```

| Before write       | After write           | Operation         |
| ------------------ | --------------------- | ----------------- |
| `onStart`          | `afterStart`          | `startResponse`   |
| `onSaveDraft`      | `afterSaveDraft`      | `saveDraft`       |
| `onSubmit`         | `afterSubmit`         | `submitResponse`  |
| `onAbandon`        | `afterAbandon`        | `abandonResponse` |
| `onReopen`         | `afterReopen`         | `reopenResponse`  |
| `onDeleteResponse` | `afterDeleteResponse` | `deleteResponse`  |
| `onSaveForm`       | `afterSaveForm`       | `saveForm`        |
| `onDeleteForm`     | `afterDeleteForm`     | `deleteForm`      |

Response hooks receive `{ request, response, getPluginContext }`.
Form hooks receive `{ request, form, getPluginContext }`.

Plugin hooks and your `hooks` are merged. See [Plugins](/docs/plugins).
