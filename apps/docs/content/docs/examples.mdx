## examples/next

Next.js App Router demo: one code-authored form, shadcn Field widgets, live
answer preview, and Drizzle + SQLite via FumaDB.

Reads go through `form.api` in Server Components (`{ query }` / `{ body }`).
Writes go through `createFormClient<Form>()` in the browser (object args).

Shared `defineFieldType` lives in `lib/field-types.ts` and imports
`@dimah-form/core` so both the server instance and the client can reuse it.
Star rating widgets live in the example. They are not part of
`@dimah-form/react`.

```bash
pnpm install
pnpm build
pnpm --filter @dimah-form/example-next db:generate
pnpm --filter @dimah-form/example-next db:push
pnpm --filter @dimah-form/example-next dev
```

Open http://localhost:3000

| Route        | What it shows                                                              |
| ------------ | -------------------------------------------------------------------------- |
| `/`          | Feedback form — built-ins plus `showWhen`; `rating` is a custom field type |
| `/f/:formId` | Same questionnaire, resolved by id or slug                                 |
| `/responses` | Stored answers (`include=full`)                                            |
| `/r/:id`     | Resume a draft, or reopen a submitted / abandoned response                 |

Save draft patches answers; submit replaces them. Both send `updatedAt`.
The demo sets `resume: true` so a returning `respondentId` reopens the
latest draft. Edit on `/r/:id` calls `reopenResponse` (same snapshot and
answers) — it does not start a new response.

Source:
[github.com/dimah-kz/dimah-form/tree/main/examples/next](https://github.com/dimah-kz/dimah-form/tree/main/examples/next)
