`@dimah-form/server` has **zero database or ORM dependencies**. Persistence is fully decoupled through the `ResponseStore` interface passed to `dimahForm({ database })`.

---

## Storage Architecture

A dimah-form database stores two core entity tables:

| Table               | Purpose                                       | Key Columns                                                                                                                |
| :------------------ | :-------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------- |
| **`questionnaire`** | Dynamic form definitions created via API      | `id`, `slug`, `title`, `definition`, `status`, `createdAt`, `updatedAt`                                                    |
| **`response`**      | Respondent fill sessions and frozen snapshots | `id`, `form_id`, `definition` (snapshot), `answers`, `status`, `respondent_id`, `submitted_at`, `created_at`, `updated_at` |

---

## 1. In-Memory Adapter (`memoryAdapter`)

For automated unit tests, CI pipelines, or local prototyping, `@dimah-form/server` includes an in-memory store that requires zero setup:

```ts title="lib/form.ts"
import { dimahForm, memoryAdapter } from "@dimah-form/server";
import { forms } from "@/lib/forms";

export const form = dimahForm({
  database: memoryAdapter(),
  forms,
});
```

### Drizzle ORM Setup

<Steps>

<Step>

#### Define Database Tables

```ts title="lib/db/schema.ts"
import { sql } from "drizzle-orm";
import { text, integer, sqliteTable } from "drizzle-orm/sqlite-core";

export const questionnaires = sqliteTable("questionnaire", {
  id: text("id").primaryKey(),
  slug: text("slug").notNull().unique(),
  title: text("title").notNull(),
  definition: text("definition", { mode: "json" }).notNull(),
  status: text("status").notNull().default("active"),
  createdAt: text("created_at")
    .default(sql`CURRENT_TIMESTAMP`)
    .notNull(),
  updatedAt: text("updated_at")
    .default(sql`CURRENT_TIMESTAMP`)
    .notNull(),
});

export const responses = sqliteTable("response", {
  id: text("id").primaryKey(),
  formId: text("form_id").notNull(),
  status: text("status").notNull().default("draft"),
  definition: text("definition", { mode: "json" }).notNull(),
  answers: text("answers", { mode: "json" }).notNull(),
  respondentId: text("respondent_id"),
  submittedAt: text("submitted_at"),
  createdAt: text("created_at")
    .default(sql`CURRENT_TIMESTAMP`)
    .notNull(),
  updatedAt: text("updated_at")
    .default(sql`CURRENT_TIMESTAMP`)
    .notNull(),
});
```

</Step>

<Step>

#### Initialize `DimahFormDB`

```ts title="lib/db/index.ts"
import { createClient } from "@libsql/client";
import { DimahFormDB } from "@dimah-form/db";
import { drizzle } from "drizzle-orm/libsql";
import { drizzleAdapter } from "fumadb/adapters/drizzle";
import * as schema from "./schema";

const client = createClient({
  url: process.env.DATABASE_URL || "file:local.db",
});
const dbInstance = drizzle({ client, schema });

export const formDb = DimahFormDB.client(
  drizzleAdapter({
    db: dbInstance,
    provider: "sqlite", // "sqlite" | "postgresql" | "mysql"
  }),
);
```

</Step>

<Step>

#### Connect to `dimahForm()`

```ts title="lib/form.ts"
import { db } from "@dimah-form/db";
import { dimahForm } from "@dimah-form/server";
import { formDb } from "@/lib/db";
import { forms } from "@/lib/forms";

export const form = dimahForm({
  database: db(formDb),
  forms,
});
```

</Step>

</Steps>

### Prisma ORM Setup

<Steps>

<Step>

#### Add Models to `prisma/schema.prisma`

```prisma title="prisma/schema.prisma"
model Questionnaire {
  id         String   @id @default(cuid())
  slug       String   @unique
  title      String
  definition Json
  status     String   @default("active")
  createdAt  DateTime @default(now()) @map("created_at")
  updatedAt  DateTime @updatedAt @map("updated_at")

  @@map("questionnaire")
}

model Response {
  id           String    @id @default(cuid())
  formId       String    @map("form_id")
  status       String    @default("draft")
  definition   Json
  answers      Json
  respondentId String?   @map("respondent_id")
  submittedAt  DateTime? @map("submitted_at")
  createdAt    DateTime  @default(now()) @map("created_at")
  updatedAt    DateTime  @updatedAt @map("updated_at")

  @@index([formId])
  @@index([respondentId])
  @@map("response")
}
```

</Step>

<Step>

#### Initialize `DimahFormDB` with Prisma Adapter

```ts title="lib/db.ts"
import { PrismaClient } from "@prisma/client";
import { DimahFormDB } from "@dimah-form/db";
import { prismaAdapter } from "fumadb/adapters/prisma";

const prisma = new PrismaClient();

export const formDb = DimahFormDB.client(
  prismaAdapter({
    prisma,
    provider: "postgresql", // "postgresql" | "sqlite" | "mysql"
  }),
);
```

Pass `db(formDb)` into `dimahForm({ database: db(formDb) })`.

</Step>

</Steps>
