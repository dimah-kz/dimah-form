Field types are validators on the instance, not React components. How to add one: [Custom fields](/docs/guides/custom-fields).

Built-ins are always registered. Extra types go in `dimahForm({ fieldTypes })`. Duplicate `type` strings throw at init.

## Built-ins

| Type | Answer | Extra keys |
| --- | --- | --- |
| `text` | string | `minLength`, `maxLength`, `pattern` |
| `number` | finite number | `min`, `max`, `integer` |
| `boolean` | boolean | — |
| `select` | string option value | `options` (`{ value, label?, meta? }[]`) |
| `multiSelect` | `string[]` | `options` (unique values) |
| `email` | string | — |
| `date` | ISO calendar date (`YYYY-MM-DD`) | — |

Shared field keys: `id`, `type`, `required`, `label`, `description`, `defaultValue`, `showWhen`, `meta`.

Blank strings are empty for `text`, `number`, `select`, `email`, and `date`. An empty array is empty for `multiSelect`. Required checks run on **submit** for **visible** fields. Draft allows empty required fields.

Select / multiSelect `options` need at least one entry. Duplicate option `value`s are rejected on the document.

`pattern` on `text` must be a valid `RegExp` source. `minLength` must be `<= maxLength` when both are set. `number` `min` must be `<= max`.

## Visibility (`showWhen`)

Skip a field when the sibling answer does not match. Hidden answers are stripped before validation.

```ts
{
  id: "team",
  type: "text",
  label: "Team",
  showWhen: { field: "role", equals: "eng" },
}
```

```ts
{
  id: "apiNote",
  type: "text",
  showWhen: { field: "highlights", includes: "api" },
}
```

`equals` uses `Object.is`. `includes` matches a value inside an array sibling (`multiSelect`). At least one of `equals` or `includes` is required; both may be set (AND).

`defaultValue` seeds a new response, then hidden fields are dropped.

## Type inference

Code-authored forms produce `form.$Infer.answers[formKey]`. Required fields are required keys; optional fields are omitted keys — the same object `parseAnswers` returns on submit.

Custom types contribute through `$Infer` on `defineFieldType` and the `fieldTypes` generic on the instance. Plugin `fieldTypes` merge into that union.

```ts
type Feedback = Form["$Infer"]["answers"]["feedback"];
// { name: string; ok: boolean; team?: string }
```

Browser `$Infer` is `createFormClient<typeof form>()` (type-only). Pass `forms` / `fieldTypes` on the client only when you do not have the server instance type. Still pass `fieldTypes` at **runtime** for `useFormResponse` local validation.
