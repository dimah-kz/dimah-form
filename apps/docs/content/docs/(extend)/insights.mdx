[`@dimah-form/insights`](https://www.npmjs.com/package/@dimah-form/insights) folds stored responses into admin counts.
It walks the same 100-row pages as list, capped at 10_000 by default. There are no tables and no `meta` namespace.

The live questionnaire only supplies field order and catalog levels that snapshots did not already list. Answers come from each row's snapshot.

This is not a warehouse. For a large N, persist with [`datasetPlugin({ onProject })`](/docs/dataset) and aggregate in your database. When the walk hits the cap, `truncated` is true. Query `maxRows` can lower the cap, not raise it. Raise it with `insightsPlugin({ maxRows })`.

## Install

```npm
npm i @dimah-form/insights
```

```ts title="lib/form.ts"
import { insightsPlugin } from "@dimah-form/insights";

export const form = dimahForm({
  database,
  forms,
  plugins: [insightsPlugin()],
});
```

```ts title="lib/form-client.ts"
"use client";

import { insightsClientPlugin } from "@dimah-form/insights/client";

const plugins = [insightsClientPlugin()] as const;
export const formClient = createFormClient<Form, typeof plugins>({ plugins });
```

Guard `getFormInsights` and `getFormCrosstab` like `listResponses`.

## Summary

`GET /insights/summary` (`getFormInsights`).

There is no default `status` filter. Dataset defaults to submitted; this plugin does not. Pass `status`, `respondentId`, `submittedFrom` / `submittedTo`, and `updatedAfter` — the same filters as `listResponses`.

```ts
const summary = await form.api.getFormInsights({
  query: { formId: "gad7", status: "submitted" },
});

const byDay = await form.api.getFormInsights({
  query: {
    formId: "gad7",
    status: "submitted",
    bucket: "day",
    timeZone: "Asia/Tehran",
  },
});
```

| Field                 |                                                                                                                                                                                                                      |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `byStatus`            | Counts for `draft`, `submitted`, `abandoned`                                                                                                                                                                         |
| `completion`          | Visible required fields on **each row's snapshot**. `rate` is `complete / submitted`, or `null`                                                                                                                      |
| `fields`              | Live questionnaire order. Ids that exist only on older snapshots come after                                                                                                                                          |
| `fields[].n`          | Visible occurrences                                                                                                                                                                                                  |
| `fields[].hidden`     | Hidden by `showWhen`                                                                                                                                                                                                 |
| `fields[].unanswered` | Visible and empty                                                                                                                                                                                                    |
| `values`              | Categorical levels (`select`, `multiSelect`, `boolean`, or any field with `options`). Document order, including `n: 0`. `pct` is 0–1. `multiSelect` percent is of answered respondents and can sum above 1           |
| `numeric`             | min / max / mean / stdev for a finite number (`number`, or a custom type such as `rating`)                                                                                                                           |
| `dates`               | min / max for `date`                                                                                                                                                                                                 |
| `scores`              | Band counts, mean, stdev from `@dimah-form/scoring` (a dependency). Band order follows `meta.scoring`, including `n: 0`. Omitted when the snapshot has no `meta.scoring`, or when that scoring meta fails validation |

`text` and `email` are answered / unanswered only.

`whereField` + `whereValue` segment the fold. An unknown field yields empty counts, not 404. A finite number matches the decimal string of the stored value (`5` matches `"5"`).

`bucket=day` groups `submittedAt` in an IANA `timeZone`. The query overrides the plugin option. Default is `UTC`. The series includes that `timeZone`.

## Crosstab

`GET /insights/crosstab` (`getFormCrosstab`). Two categorical fields. `n` is respondents who contributed a cell, not `multiSelect` tokens. `table.n` is the respondent base for the cells.

```ts
const table = await form.api.getFormCrosstab({
  query: { formId: "gad7", row: "city", col: "remote", status: "submitted" },
});
```

An axis counts only on snapshots where that field is categorical. Changing the live field to `text` does not drop older select rows, and it does not reject the query. An id that exists only on older snapshots still folds.

## Out of this package

Weighted samples, charts, saved summaries, and LLM writeups. Files are [Dataset](/docs/dataset). `@dimah-form/ui` renders the fill session, not an admin dashboard.
