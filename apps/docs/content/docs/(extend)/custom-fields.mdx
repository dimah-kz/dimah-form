A custom field type is a validator and an `$Infer` token. It is not a React component.
You render the control, or register a widget on [`@dimah-form/ui`](/docs/ui).

Put `defineFieldType` in a module both sides import. `@dimah-form/core` is the shared entry. Server-only files may import it from `@dimah-form/server`.

```ts title="lib/field-types/rating.ts"
import { defineFieldType } from "@dimah-form/core";
import * as z from "zod";

export const ratingFieldType = defineFieldType({
  type: "rating",
  fieldSchema: z.looseObject({
    type: z.literal("rating"),
    min: z.number().int().min(1).default(1),
    max: z.number().int().max(10).default(5),
  }),
  isEmpty: (value) => value == null,
  validate: (value, field) => {
    if (typeof value !== "number" || !Number.isInteger(value)) {
      return { code: "EXPECTED_INTEGER", message: "Rating must be an integer" };
    }
    const min = field.min ?? 1;
    const max = field.max ?? 5;
    if (value < min) {
      return {
        code: "TOO_SMALL",
        message: `Rating must be at least ${min}`,
        params: { min },
      };
    }
    if (value > max) {
      return {
        code: "TOO_LARGE",
        message: `Rating cannot exceed ${max}`,
        params: { max },
      };
    }
  },
  $Infer: 0 as number,
  format: (value, field) =>
    typeof value === "number" ? `${value}/${field.max ?? 5}` : "",
});

export const fieldTypes = [ratingFieldType] as const;
```

## Register

Pass the same array to the server and the client. `$Infer` from `createFormClient<Form>()` does not install validators.

```ts title="lib/form.ts"
export const form = dimahForm({
  database: memoryAdapter(),
  fieldTypes,
  forms,
});
```

```ts title="lib/form-client.ts"
"use client";

export const formClient = createFormClient<Form>({
  basePath: "/api/form",
  fieldTypes,
});
```

A plugin can own the list. The client plugin must repeat it — do not pass `fieldTypes` twice.

```ts
export const ratingPlugin = definePlugin({
  id: "rating",
  fieldTypes,
});

export const ratingClient = defineClientPlugin({
  id: "rating",
  fieldTypes,
});
```

## Author

`defineForm` stays loose JSON at runtime. `createDefineForm` only types the document. Still pass `fieldTypes` into `dimahForm()` and `createFormClient()`.

```ts title="lib/forms/review.ts"
import { createDefineForm } from "@dimah-form/server";
import type { FormDefinitionUi } from "@dimah-form/ui/types";
import { fieldTypes } from "@/lib/field-types/rating";

const defineAppForm = createDefineForm({ fieldTypes });

export const reviewForm = defineAppForm({
  title: "Product review",
  slug: "review",
  fields: [
    {
      id: "score",
      type: "rating",
      label: "Stars",
      required: true,
      min: 1,
      max: 5,
    },
    { id: "comments", type: "text", label: "Comments" },
  ],
} satisfies FormDefinitionUi<typeof fieldTypes>);
```

Drop `satisfies FormDefinitionUi` when you do not use `@dimah-form/ui`.
`Form["$Infer"]["answers"]["review"]["score"]` is `number`.

## Widget

Register under the same `type` string. The widget receives `{ binding, className, mode }`.

```tsx
import {
  FormFieldFrame,
  FormUiProvider,
  FormView,
  fieldNumber,
  type FieldWidgetProps,
} from "@dimah-form/ui";

function StarRatingField({
  binding,
  className,
  mode,
}: FieldWidgetProps<number>) {
  const max = fieldNumber(binding.field, "max") ?? 5;
  const review = mode === "review";

  return (
    <FormFieldFrame binding={binding} className={className}>
      <StarRating
        value={binding.value}
        max={max}
        disabled={binding.disabled || review}
        onChange={(value) => {
          if (!review) binding.onChange(value);
        }}
      />
    </FormFieldFrame>
  );
}

<FormUiProvider widgets={{ rating: StarRatingField }}>
  <FormView form={form} />
</FormUiProvider>;
```

On the headless path, branch on `field.type === "rating"` in your dispatcher. See [Widgets](/docs/widgets).
