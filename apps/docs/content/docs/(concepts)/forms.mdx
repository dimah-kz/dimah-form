Forms are TypeScript (`defineForm`) or rows you save with `saveForm`.
Code-authored forms feed `$Infer`. Database forms do not.

```ts title="lib/forms/onboarding.ts"
import { defineForm } from "@dimah-form/server";

export const onboardingForm = defineForm({
  title: "Employee Onboarding",
  slug: "onboarding",
  status: "active",
  fields: [
    {
      id: "fullName",
      type: "text",
      label: "Full name",
      required: true,
      minLength: 2,
      maxLength: 100,
    },
    {
      id: "department",
      type: "select",
      label: "Department",
      required: true,
      options: [
        { value: "engineering", label: "Engineering" },
        { value: "design", label: "Design" },
      ],
    },
    {
      id: "github",
      type: "text",
      label: "GitHub",
      required: true,
      showWhen: { field: "department", equals: "engineering" },
    },
  ],
});
```

```ts title="lib/form.ts"
import { dimahForm, memoryAdapter } from "@dimah-form/server";
import { onboardingForm } from "@/lib/forms/onboarding";

export const form = dimahForm({
  database: memoryAdapter(),
  forms: { onboarding: onboardingForm },
});

export type Form = typeof form;
```

The catalog key and `slug` may differ. `getForm` and `startResponse` accept either `id` or `slug`.

If you render with `@dimah-form/ui`, add `satisfies FormDefinitionUi` so `meta` keys type-check. See [UI](/docs/ui). Custom field types use `createDefineForm` — see [Custom fields](/docs/custom-fields).

## Properties

| Property      | Default     |                                                                         |
| ------------- | ----------- | ----------------------------------------------------------------------- |
| `title`       | —           | Shown to the respondent                                                 |
| `slug`        | Catalog key | Lookup alias for `id`                                                   |
| `description` | —           | Optional instructions                                                   |
| `status`      | `"active"`  | `"draft"` and `"archived"` reject `startResponse` (`409 FORM_INACTIVE`) |
| `fields`      | `[]`        | Field definitions                                                       |
| `meta`        | `{}`        | Opaque JSON. UI hints and plugin namespaces live here                   |

## Fields

```ts
{
  id: "workEmail",
  type: "email",
  label: "Work email",
  required: true,
  description: "We send the packet here.",
  meta: { placeholder: "you@company.com" },
}
```

| Property       |                                                |
| -------------- | ---------------------------------------------- |
| `id`           | Answer key. Unique in the form                 |
| `type`         | Built-in type, or a `defineFieldType` key      |
| `label`        | `fieldLabel(field)` falls back to `id`         |
| `required`     | Enforced on submit when the field is visible   |
| `defaultValue` | Seeded by `startResponse`                      |
| `showWhen`     | Hides the field and drops its answer on submit |
| `description`  | Helper copy. `@dimah-form/ui` renders it       |
| `meta`         | Opaque JSON for widgets and plugins            |

Built-in types and per-type constraints: [Field types](/docs/field-types).

## showWhen

A hidden field leaves `visibleFields`. Submit strips its answer.

```ts
showWhen: { field: "role", equals: "manager" }
showWhen: { field: "plan", notEquals: "free" }
showWhen: { field: "stack", includes: "typescript" } // multiSelect

showWhen: {
  all: [
    { field: "experience", equals: "senior" },
    { field: "location", equals: "remote" },
  ],
}

showWhen: {
  any: [
    { field: "department", equals: "engineering" },
    { field: "department", equals: "product" },
  ],
}
```

## Code and database

|                           | `forms: {}`                     | `saveForm`                             |
| ------------------------- | ------------------------------- | -------------------------------------- |
| Types                     | `Form["$Infer"]["answers"]`     | `Record<string, unknown>`              |
| Storage                   | Git                             | `questionnaire` row                    |
| `saveForm` / `deleteForm` | Rejected (`CODE_AUTHORED_FORM`) | Allowed when the form has no responses |

## $Infer

```ts
type OnboardingAnswers = Form["$Infer"]["answers"]["onboarding"];
// {
//   fullName: string;
//   department: "engineering" | "design";
//   github?: string;
// }
```

```tsx
const q = useFormResponse<"onboarding">({ snapshot });
```

Optional fields are those without `required: true`.
