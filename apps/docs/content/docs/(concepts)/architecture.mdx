The library owns the protocol, definition snapshots, and submit validation.
Your app owns widgets, auth, and the `database` adapter.

<ArchitectureDiagram />

## Packages

| Package                | Runs                | Owns                                                   |
| ---------------------- | ------------------- | ------------------------------------------------------ |
| `@dimah-form/core`     | Universal           | Routes, Zod payloads, field validators, error codes    |
| `@dimah-form/server`   | Server              | `dimahForm()`, adapters, `form.api`, `memoryAdapter()` |
| `@dimah-form/react`    | Browser             | `createFormClient()`, `useFormResponse()`              |
| `@dimah-form/ui`       | Browser             | Optional renderer over `FormResponseApi`               |
| `@dimah-form/db`       | Server              | Optional SQL `ResponseStore`                           |
| `@dimah-form/scoring`  | Server / isomorphic | Optional `meta.scoring` totals                         |
| `@dimah-form/dataset`  | Server / isomorphic | Optional JSONL + codebook                              |
| `@dimah-form/insights` | Server / isomorphic | Optional snapshot summaries                            |

Apps import `@dimah-form/server` on the server and `@dimah-form/react` in the browser.
Share types with `export type Form = typeof form` and `createFormClient<Form>()`.

Persistence is `database`, not a plugin. Plugins add endpoints, hooks, field types, and `meta` checks.

## Request pipeline

Every operation runs the same stages:

<Flow
  label="Request pipeline"
  steps={[
    { name: "Parse", kind: "protocol", note: "Zod" },
    { name: "Guard", kind: "server", note: "Your auth" },
    { name: "Validate", kind: "protocol", note: "Snapshot" },
    { name: "on*", kind: "server", note: "Before write" },
    { name: "Store", kind: "data", note: "CAS on updatedAt" },
    { name: "after*", kind: "server", note: "After write" },
  ]}
/>

1. **Parse** — query and body must match the protocol schema. Failure is `400 VALIDATION_ERROR`.
2. **Guard** — optional. Throw to reject before any form logic.
3. **Validate** — draft and submit checks use `response.definition`, not the live form. Submit strips hidden `showWhen` fields.
4. **`on*`** — mutate the in-memory record (`response.respondentId = user.id`). A throw aborts the write.
5. **Store** — if `updatedAt` was sent, a mismatch is `409 STALE_UPDATE`.
6. **`after*`** — email, webhooks, and other side effects. The row is already stored.
