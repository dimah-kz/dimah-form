[`@dimah-form/db`](https://www.npmjs.com/package/@dimah-form/db) is the
FumaDB adapter for `dimahForm({ database })`.

Persistence is first-class on the server instance, not a plugin. This
package peers on `@dimah-form/server` and must not be imported from
`@dimah-form/core` or the React client.

## When to use it

- **`memoryAdapter()`** (`@dimah-form/server`) — tests, demos, ephemeral state
- **`db()`** (this package) — questionnaires and responses on FumaDB
  (Drizzle, Prisma, and other FumaDB orms)

The [Next.js example](/docs/examples) uses FumaDB + Drizzle RC + local
SQLite.

## Ownership

- `getForm` / `startResponse` resolve code-authored `forms` first (id then
  slug), then `database.getForm`.
- `saveForm` upserts the live questionnaire. Starting a response inserts
  the parent questionnaire row if it is missing and never overwrites the
  live definition.
- `deleteForm` refuses code-authored ids and forms that still have
  responses (archive via `status` instead).
- `listResponses` defaults to summaries; `include=full` returns stored
  answers.

A custom store is allowed — pass it to `database` directly, not through
`db()`. Plugins must not add tables.

See [Architecture](/docs/architecture) for why persistence is not a plugin.
