dimah-form is a backend-first questionnaire engine for React and Node.js.
It owns the protocol, per-response definition snapshots, drafts, and submit validation.
Your application owns authentication, persistence, and rendering.

Use it when a questionnaire belongs inside your product and must keep its original definition after the live form changes.
It is not a visual builder, hosted survey service, authentication system, or analytics warehouse.

## The model

<Flow
  label="One response"

When a response starts, the server stores a copy of the active form in
`response.definition`. Later edits to the live questionnaire do not affect
that draft or submitted response.

## What you install

| Need                                    | Package                                      |
| --------------------------------------- | -------------------------------------------- |
| Server instance, handler, and adapters  | `@dimah-form/server`                         |
| React client and fill session           | `@dimah-form/react`                          |
| Production SQL adapter                  | `@dimah-form/db`                             |
| Optional shadcn renderer                | `@dimah-form/ui`                             |
| Optional scoring, export, and summaries | `@dimah-form/scoring`, `dataset`, `insights` |

`database` is required on `dimahForm()`. SQL is optional: use
`memoryAdapter()` for tests and local development, or a persistent
`ResponseStore` in production.
