dimah-form is a **backend-first questionnaire engine**. It owns the HTTP protocol, definition snapshots, drafts, and submit validation. You own rendering, authentication, and the database adapter.

It is not a form renderer, not a field-widget kit, and not a hosted survey product. There is no shadcn registry.

<Callout>
  Two rules everything else hangs on: **consumers own UI**, and **submit validates the snapshot stored on the response**, not the live questionnaire.
</Callout>

## What it is not

- A drop-in form UI or visual builder
- An auth library — put policy in your `guard`
- An ORM — `@dimah-form/server` does not import one
- A questionnaire version table — old fills keep their snapshot on the response

Use it when you need typed questionnaires with drafts and snapshot-safe submit, and you already have (or want) your own widgets. Skip it when you want a ready-made renderer or a hosted survey SaaS.

## Package map

| Package | You use it for |
| --- | --- |
| `@dimah-form/server` | `dimahForm()`, HTTP `handler`, `form.api`, adapters |
| `@dimah-form/react` | `createFormClient`, `useFormResponse` — no widgets |
| `@dimah-form/db` | FumaDB `database` adapter (`db()`) |
| `@dimah-form/core` | Protocol SSOT. App code imports `server` or `react`; shared `defineFieldType` modules import `core` |

```
@dimah-form/core
        ↓
@dimah-form/server | @dimah-form/react
        ↑
@dimah-form/db   (peer of server)
```

`database` is required: `memoryAdapter()` from server, or `db()` from `@dimah-form/db`. Custom stores implement `ResponseStore` and pass that object to `database` directly.

## Mental model

1. You author a **questionnaire** (`defineForm`) or persist one with `saveForm`.
2. `startResponse` copies the **live definition** onto the response. That copy is the **snapshot**.
3. Drafts patch answers. Submit **replaces** answers and validates them against the snapshot.
4. Your React tree calls `useFormResponse` and renders `visibleFields`. The library never mounts an input.

Auth is a `guard` on the instance. Custom fields are `defineFieldType` **validators** that feed `$Infer`, not React components.

Share types with `export type Form = typeof form` and `createFormClient<Form>()`. Do not pass the server instance into the browser.
