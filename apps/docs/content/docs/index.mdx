**dimah-form** is a headless, type-safe questionnaire engine. It provides the backend runtime, schema snapshots, draft management, and validation pipeline for complex forms and surveys—while leaving UI widgets, authentication, and database persistence completely in your control.

## Why dimah-form?

Building multi-step questionnaires, surveys, and onboarding flows is deceptively complex. Real-world forms face three major challenges that standard client-side form libraries cannot solve:

1. **Schema Drift During Long Fills**: If an admin updates a questionnaire while a user is filling out a draft, validating against the live schema breaks the draft. dimah-form freezes an exact snapshot of the definition at fill start time.
2. **Drafts & Optimistic Concurrency**: Respondents switch devices or have unstable network connections. dimah-form provides automated draft saving with `updatedAt` Compare-And-Swap (CAS) tokens to prevent overwrites.
3. **Headless Freedom with Server Validation**: You build your own UI using your design system (Tailwind, shadcn/ui, Radix), while dimah-form ensures answers are strictly validated on the server against the frozen snapshot.

## Package Ecosystem

The repository is structured as a focused TypeScript monorepo with distinct separation of concerns:

```
@dimah-form/core (Protocol SSOT, Schemas, Validators, Types)
        ↓
@dimah-form/server  ←───  @dimah-form/db (FumaDB / Drizzle / Prisma)
        │
@dimah-form/react   (useFormResponse, Form client)
```

| Package                  | Environment              | Purpose                                                                                 |
| :----------------------- | :----------------------- | :-------------------------------------------------------------------------------------- |
| **`@dimah-form/core`**   | Shared (Universal)       | Protocol SSOT, Zod schemas, field validators, error codes, and TypeScript types.        |
| **`@dimah-form/server`** | Server (Node / Edge)     | `dimahForm()` engine, HTTP framework adapters, `form.api`, and `memoryAdapter()`.       |
| **`@dimah-form/react`**  | Browser (`"use client"`) | `createFormClient()`, `useFormResponse()`, field binding helpers, and state management. |
| **`@dimah-form/db`**     | Server                   | Production persistence adapter powered by FumaDB (supports Drizzle and Prisma).         |
