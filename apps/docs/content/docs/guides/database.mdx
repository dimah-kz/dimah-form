Persistence is the `database` option on `dimahForm()`. It is not a plugin. `@dimah-form/server` does not import an ORM.

- **`memoryAdapter()`** (`@dimah-form/server`) — tests, demos, ephemeral state. Isolated per call.
- **`db()`** (`@dimah-form/db`) — questionnaires and responses on [FumaDB](https://github.com/fuma-nama/fumadb)
- **Custom `ResponseStore`** — pass the object to `database` directly, not through `db()`

The [Next.js example](/docs/examples) uses FumaDB + Drizzle + local SQLite.

## What it stores

Two application tables. There is no version table — old responses keep their snapshot on `response.definition`.

| Table | Role |
| --- | --- |
| `questionnaire` | Live form (`id`, `slug`, `title`, `definition`, `status`, timestamps) |
| `response` | Fill (`definition` copy at start, `answers`, `status`, `respondentId`) |

FumaDB also keeps a private settings row (`private_dimah_form_settings`). Do not write to it from application code.

`response.questionnaire_id` is a foreign key to `questionnaire.id` (`onDelete: restrict`). Starting a response inserts the parent questionnaire if it is missing and never overwrites the live definition.

## FumaDB

```npm
npm i @dimah-form/db fumadb
```

`@dimah-form/server` is a peer.

Generate adapter-specific tables from `DimahFormDB`, or copy the [example schema](https://github.com/dimah-kz/dimah-form/blob/main/examples/next/lib/schema.ts).

Call `DimahFormDB.client(…).generateSchema("1.0.0")` and write `generated.code` next to your ORM schema. The [Next.js example script](https://github.com/dimah-kz/dimah-form/blob/main/examples/next/scripts/generate-schema.mjs) does this for Drizzle. Keep the generated `private_dimah_form_settings` table.

<Tabs items={["Drizzle", "Prisma"]}>

<Tab value="Drizzle">

```ts title="lib/db.ts"
import { createClient } from "@libsql/client";
import { DimahFormDB } from "@dimah-form/db";
import { drizzle } from "drizzle-orm/libsql";
import { drizzleAdapter } from "fumadb/adapters/drizzle";
import { relations } from "./schema";

const sqlite = createClient({ url: "file:local.db" });
const orm = drizzle({ client: sqlite, relations });

export const formDb = DimahFormDB.client(
  drizzleAdapter({
    db: orm,
    provider: "sqlite", // or "postgresql" | "mysql"
  }),
);
```

</Tab>

<Tab value="Prisma">

```ts title="lib/dimah-form-db.ts"
import { prismaAdapter } from "fumadb/adapters/prisma";
import { DimahFormDB } from "@dimah-form/db";
import { prisma } from "@/lib/db";

export const formDb = DimahFormDB.client(
  prismaAdapter({ prisma, provider: "postgresql" }),
);
```

</Tab>

</Tabs>

```ts title="lib/form.ts"
import { db } from "@dimah-form/db";
import { dimahForm } from "@dimah-form/server";
import { formDb } from "@/lib/db";

export const form = dimahForm({
  database: db(formDb),
});
```

You may query these tables from your own ORM. Submit validation still belongs on `dimahForm()` — do not bypass it with raw writes to `response.answers`.

## Custom store

`ResponseStore` is the adapter contract (`getForm`, `saveForm`, `deleteForm`, `listForms`, `create`, `get`, `save`, `delete`, `listResponses`). Methods may be sync or async. See [Configuration](/docs/reference/configuration).
