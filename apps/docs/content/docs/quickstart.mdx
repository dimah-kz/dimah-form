A working questionnaire with drafts, `showWhen` visibility, and server validation. After this page, read [Architecture](/docs/architecture) for the model or [React](/docs/react) for the fill hook.

<Steps>

<Step>

### 1. Install Dependencies

Install `@dimah-form/server` for backend routes and `@dimah-form/react` for the React client hook:

<Tabs items={["pnpm", "npm", "yarn", "bun"]}>

<Tab value="pnpm">
  ```bash pnpm add @dimah-form/server @dimah-form/react ```
</Tab>

<Tab value="npm">
  ```bash npm install @dimah-form/server @dimah-form/react ```
</Tab>

<Tab value="yarn">
  ```bash yarn add @dimah-form/server @dimah-form/react ```
</Tab>

<Tab value="bun">```bash bun add @dimah-form/server @dimah-form/react ```</Tab>

</Tabs>

</Step>

<Step>

### 2. Define Your Form Schema

Create your form definitions under `lib/forms/`. Each form is defined using `defineForm`:

```ts title="lib/forms/feedback.ts"
import { defineForm } from "@dimah-form/server";

export const feedbackForm = defineForm({
  title: "Product Feedback",
  slug: "feedback",
  description: "Help us improve our service with your honest feedback.",
  fields: [
    {
      id: "fullName",
      type: "text",
      label: "Full Name",
      required: true,
    },
    {
      id: "rating",
      type: "select",
      label: "How would you rate your experience?",
      required: true,
      options: [
        { value: "great", label: "Great" },
        { value: "ok", label: "Okay" },
        { value: "poor", label: "Poor" },
      ],
    },
    {
      id: "improvements",
      type: "text",
      label: "What could we improve?",
      required: true,
      showWhen: {
        field: "rating",
        equals: "poor",
      },
    },
  ],
});
```

Export all forms from a central forms catalog:

```ts title="lib/forms/index.ts"
import { feedbackForm } from "./feedback";

export const forms = {
  feedback: feedbackForm,
};
```

</Step>

<Step>

### 3. Initialize the Server Instance

Configure `dimahForm()` with your forms catalog and a persistence adapter. For this quickstart, we use the built-in `memoryAdapter()`:

```ts title="lib/form.ts"
import { dimahForm, memoryAdapter } from "@dimah-form/server";
import { forms } from "@/lib/forms";

export const form = dimahForm({
  database: memoryAdapter(),
  forms,
  basePath: "/api/form",
});

export type Form = typeof form;
```

<Callout type="info">
  Exporting `export type Form = typeof form` exposes the inferred `$Infer`
  answer types so your React client has 100% end-to-end type safety.
</Callout>

</Step>

<Step>

### 4. Mount the Route Handler

Create a Next.js App Router catch-all route handler to serve the REST API:

```ts title="app/api/form/[...all]/route.ts"
import { toNextJsHandler } from "@dimah-form/server/next";
import { form } from "@/lib/form";

export const { GET, POST, PUT, PATCH, DELETE } = toNextJsHandler(form);
```

This single route handler automatically mounts all endpoints for fetching forms, starting response sessions, saving drafts, and submitting answers.

</Step>

<Step>

### 5. Create the Type-Safe React Client

Initialize your client in a shared client file:

```ts title="lib/form-client.ts"
"use client";

import { createFormClient } from "@dimah-form/react";
import type { Form } from "@/lib/form";

export const formClient = createFormClient<Form>({
  basePath: "/api/form",
});

export const { useFormResponse } = formClient;
```

</Step>

<Step>

### 6. Build the Questionnaire UI Component

Build a React component using `useFormResponse`. The hook manages field visibility (`q.visibleFields`), local state, draft saving, and submit validation:

```tsx title="components/questionnaire.tsx"
"use client";

import { emptyToNull, fieldLabel, fieldOptions } from "@dimah-form/react";
import type { FormSnapshot } from "@dimah-form/react";
import { useFormResponse } from "@/lib/form-client";
import type { Form } from "@/lib/form";

interface QuestionnaireProps {
  form: FormSnapshot;
}

export function Questionnaire({ form }: QuestionnaireProps) {
  const q = useFormResponse<Form["$Infer"]["answers"]["feedback"]>({
    snapshot: form,
    autosave: { debounceMs: 1000 },
    onSubmitted: (res) => {
      alert(`Thank you! Response recorded with ID: ${res.id}`);
    },
  });

  if (q.inactive) {
    return <p className="text-gray-500">This form is currently inactive.</p>;
  }

  if (q.status === "submitted") {
    return (
      <div className="rounded-lg border border-green-200 bg-green-50 p-6 text-center">
        <h3 className="text-lg font-semibold text-green-900">Submitted!</h3>
        <p className="mt-1 text-sm text-green-700">
          Your feedback has been successfully recorded.
        </p>
      </div>
    );
  }

  return (
    <form
      onSubmit={(e) => {
        e.preventDefault();
        void q.submit();
      }}
      className="mx-auto max-w-lg space-y-6 rounded-xl border border-gray-200 bg-white p-6 shadow-sm"
    >
      <div>
        <h2 className="text-xl font-bold text-gray-900">{form.title}</h2>
        {form.description && (
          <p className="mt-1 text-sm text-gray-600">{form.description}</p>
        )}
      </div>

      {q.visibleFields.map((field) => {
        const binding = q.field(field.id);

        if (field.type === "select") {
          return (
            <div key={field.id} className="space-y-1.5">
              <label className="block text-sm font-medium text-gray-800">
                {fieldLabel(field)}
                {binding.required && (
                  <span className="ml-1 text-red-500">*</span>
                )}
              </label>
              <select
                value={typeof binding.value === "string" ? binding.value : ""}
                disabled={binding.disabled}
                onChange={(e) => binding.onChange(emptyToNull(e.target.value))}
                className="w-full rounded-md border border-gray-300 px-3 py-2 focus:ring-2 focus:ring-black focus:outline-none"
              >
                <option value="">Select an option...</option>
                {fieldOptions(field).map((opt) => (
                  <option key={opt.value} value={opt.value}>
                    {opt.label}
                  </option>
                ))}
              </select>
              {binding.error && (
                <p className="text-xs text-red-600">{binding.error}</p>
              )}
            </div>
          );
        }

        return (
          <div key={field.id} className="space-y-1.5">
            <label className="block text-sm font-medium text-gray-800">
              {fieldLabel(field)}
              {binding.required && <span className="ml-1 text-red-500">*</span>}
            </label>
            <input
              type="text"
              value={typeof binding.value === "string" ? binding.value : ""}
              disabled={binding.disabled}
              onChange={(e) => binding.onChange(emptyToNull(e.target.value))}
              className="w-full rounded-md border border-gray-300 px-3 py-2 focus:ring-2 focus:ring-black focus:outline-none"
            />
            {binding.error && (
              <p className="text-xs text-red-600">{binding.error}</p>
            )}
          </div>
        );
      })}

      {q.error && (
        <div className="rounded border border-red-200 bg-red-50 p-3 text-sm text-red-700">
          {q.error}
        </div>
      )}

      <div className="flex items-center justify-between pt-2">
        <button
          type="button"
          disabled={q.pending !== undefined || q.locked}
          onClick={() => void q.saveDraft()}
          className="rounded-md border border-gray-300 px-4 py-2 text-sm font-medium text-gray-700 hover:bg-gray-50 disabled:opacity-50"
        >
          {q.pending === "save" ? "Saving..." : "Save Draft"}
        </button>

        <button
          type="submit"
          disabled={q.pending !== undefined || q.locked}
          className="rounded-md bg-black px-5 py-2 text-sm font-medium text-white hover:bg-gray-800 disabled:opacity-50"
        >
          {q.pending === "submit" ? "Submitting..." : "Submit Feedback"}
        </button>
      </div>
    </form>
  );
}
```

</Step>

<Step>

### 7. Render on a Server Page

Fetch the form definition on the server using `form.api.getForm` and pass it directly to the client component:

```tsx title="app/page.tsx"
import { Questionnaire } from "@/components/questionnaire";
import { form } from "@/lib/form";
import { notFound } from "next/navigation";

export default async function Page() {
  const snapshot = await form.api.getForm({
    query: { formId: "feedback" },
  });

  if (!snapshot) {
    notFound();
  }

  return (
    <main className="min-h-screen bg-gray-50 px-4 py-12">
      <Questionnaire form={snapshot} />
    </main>
  );
}
```

</Step>

</Steps>

---

## What Just Happened?

1. **Schema Immutability**: When `useFormResponse` starts or saves a draft, dimah-form freezes the form definition into a snapshot.
2. **Dynamic Visibility**: Changing the rating to `"poor"` immediately reveals the conditional `improvements` field without custom boolean flags.
3. **Drafts & Autosave**: The questionnaire debounces changes and persists drafts to the server automatically.
4. **Server-Side Validation**: Submitting validates the answers strictly against the frozen snapshot schema on the server.
