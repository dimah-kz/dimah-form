[`@dimah-form/react`](https://www.npmjs.com/package/@dimah-form/react) is the headless fill session.
It tracks visible fields, local answers, autosave, and submit. It does not ship inputs.

```ts title="lib/form-client.ts"
"use client";

import { createFormClient } from "@dimah-form/react";
import type { Form } from "@/lib/form";

export const formClient = createFormClient<Form>({
  basePath: "/api/form",
});

export const { useFormResponse } = formClient;
```

Prefer the bound hook from your client. The unbound `useFormResponse` import needs `formClient.Provider`.

`basePath` must match the server. Cross-origin cookies and auth headers: [Auth](/docs/auth). Full option list: [Configuration](/docs/configuration).

## Fill session

```tsx title="components/questionnaire.tsx"
"use client";

import { emptyToNull, fieldLabel } from "@dimah-form/react";
import type { FormSnapshot } from "@dimah-form/react";
import { useFormResponse } from "@/lib/form-client";

export function Questionnaire({ form }: { form: FormSnapshot }) {
  const q = useFormResponse<"onboarding">({
    snapshot: form,
    autosave: { debounceMs: 1000 },
    onSubmitted: (row) => {
      console.log(row.id);
    },
  });

  if (q.inactive) return <p>This form is inactive.</p>;

  return (
    <form
      onSubmit={(event) => {
        event.preventDefault();
        void q.submit();
      }}
    >
      {q.visibleFields.map((field) => {
        const binding = q.field(field.id);
        return (
          <label key={field.id}>
            {fieldLabel(field)}
            <input
              value={typeof binding.value === "string" ? binding.value : ""}
              disabled={binding.disabled}
              onChange={(event) =>
                binding.onChange(emptyToNull(event.target.value))
              }
            />
            {binding.error ? <span>{binding.error}</span> : null}
          </label>
        );
      })}
      <button type="submit" disabled={q.pending !== undefined || q.locked}>
        Submit
      </button>
    </form>
  );
}
```

Pass `response` when you already loaded a row. The hook does not fetch the snapshot — load it with `form.api.getForm` or `getForm` on the client.

Branch on `field.type` yourself, or render with [`FormView`](/docs/ui).

## State

| Property                   |                                                                            |
| -------------------------- | -------------------------------------------------------------------------- |
| `visibleFields`            | Fields whose `showWhen` matches current answers                            |
| `answers`                  | Local answer map                                                           |
| `status`                   | `"draft"`, `"submitted"`, or `"abandoned"`                                 |
| `dirty`                    | Local answers differ from the last server row                              |
| `pending`                  | `"save"`, `"submit"`, `"reopen"`, `"abandon"`, `"refresh"`, or `undefined` |
| `locked`                   | `status !== "draft"`                                                       |
| `inactive`                 | No row yet, and the live form is not `"active"`                            |
| `error` / `errorCode`      | Last failed operation                                                      |
| `issues` / `issueCodes`    | Field id → message / code (`REQUIRED`, `TOO_SHORT`, …)                     |
| `completion`               | `{ required, answered, complete }` for visible required fields             |
| `responseId` / `updatedAt` | Current row. `updatedAt` is the compare-and-swap token                     |
| `autosave`                 | Debounced save is enabled                                                  |

## Actions

| Call                                         |                                                          |
| -------------------------------------------- | -------------------------------------------------------- |
| `field(id)`                                  | Binding for one control. `onChange(null)` clears the key |
| `setAnswer(id, value)` / `setAnswers(patch)` | Local update. `null` removes a key                       |
| `saveDraft()`                                | Persist a partial patch                                  |
| `submit()`                                   | Validate visible fields, then lock as `"submitted"`      |
| `reopen()` / `abandon()`                     | Unlock a locked row, or close a draft                    |
| `refresh()`                                  | Replace local state with the server row                  |
| `validate()`                                 | Run checks without submitting                            |

`field(id)` returns `{ id, field, value, error, errorCode, errorParams, invalid, visible, required, disabled, onChange }`.

## Options

| Option                                                                 |                                                                                      |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `snapshot`                                                             | Required. Live form or `response.definition`                                         |
| `response`                                                             | Existing row to edit                                                                 |
| `respondentId`                                                         | `string` or `() => string`                                                           |
| `resume`                                                               | Reattach the latest draft for that respondent on first save. Requires `respondentId` |
| `autosave`                                                             | Off by default. `true` debounces at 600ms, or pass `{ debounceMs }`                  |
| `validate`                                                             | `"submit"` (default) or `"change"`                                                   |
| `onStarted` / `onSaved` / `onSubmitted` / `onReopened` / `onAbandoned` | After the matching call succeeds                                                     |

`"submit"` checks on submit. After a failed submit, edits clear resolved issues.
`"change"` also checks on each answer change.

## Frequently asked questions

<Accordions>

<Accordion title="How do I show a select, checkbox, or number?">

`q.field(id)` is untyped at the DOM boundary — narrow `value` yourself, or use the helpers on [Widgets](/docs/widgets). `@dimah-form/ui` already maps built-in types.

</Accordion>

<Accordion title="How do I localize a field error?">

Read `binding.errorCode` and `binding.errorParams`. English `binding.error` is the fallback. Codes: [Errors](/docs/errors).

</Accordion>

</Accordions>
