`q.field(id)` is the contract for a control. Pass it to your input, shadcn, or design system.

[`@dimah-form/ui`](/docs/ui) wraps the same binding. This page is the headless path.

```ts
type FormFieldBinding = {
  id: string;
  field?: FormField;
  value: unknown;
  error?: string;
  errorCode?: string;
  errorParams?: Record<string, string | number>;
  invalid: boolean;
  visible: boolean;
  required: boolean;
  disabled: boolean;
  onChange: (value: unknown) => void; // null clears the key
};
```

```tsx title="components/select-field.tsx"
"use client";

import { emptyToNull, fieldLabel, fieldOptions } from "@dimah-form/react";
import type { FormFieldBinding } from "@dimah-form/react";

export function SelectField(binding: FormFieldBinding) {
  const { field, value, error, disabled, onChange } = binding;
  if (!field) return null;

  return (
    <label>
      {fieldLabel(field)}
      <select
        value={typeof value === "string" ? value : ""}
        disabled={disabled}
        onChange={(event) => onChange(emptyToNull(event.target.value))}
      >
        <option value="">Select…</option>
        {fieldOptions(field).map((option) => (
          <option key={option.value} value={option.value}>
            {option.label}
          </option>
        ))}
      </select>
      {error ? <span>{error}</span> : null}
    </label>
  );
}
```

Branch the rest on `field.type` inside one dispatcher: checkbox for `boolean`, checkboxes for `multiSelect`, `type="number"` / `type="date"` / `type="email"` for the others. `file` is metadata your app writes after upload — there is no file input in the protocol.

`onChange(null)` deletes the answer. `emptyToNull("")` does that for text controls. An empty `multiSelect` should be `null`, not `[]`, when you want the key removed.

## Helpers

Exported from `@dimah-form/react` and `@dimah-form/server`:

| Helper                                    |                                                                                                   |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------- |
| `fieldLabel(field)`                       | `field.label ?? field.id`                                                                         |
| `fieldOptions(field)`                     | `{ value, label?, meta? }`, label falls back to `value`                                           |
| `emptyToNull(value)`                      | `""` → `null`                                                                                     |
| `formatAnswer(field, value, fieldTypes?)` | English display string. Custom types use `defineFieldType.format` when `fieldTypes` includes them |

## Steps

Filter `q.visibleFields` by `field.meta.step` yourself.
`@dimah-form/ui` groups the same key with `FormSteps`. `visibleSteps` is exported from that package.
