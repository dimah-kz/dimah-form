[`@dimah-form/ui`](https://www.npmjs.com/package/@dimah-form/ui) renders a `useFormResponse` result.
It does not call the hook. `@dimah-form/react` stays headless if you skip this package.

Built-in widgets cover `text`, `email`, `date`, `number`, `boolean`, `select`, and `multiSelect`.
`file` has no widget — register one, or write the answer after your own upload.
A custom `defineFieldType` registers on `FormUiProvider` under the same `type` string. `meta.widget` swaps one field without replacing the type.

## Install

```npm
npm i @dimah-form/ui @dimah-form/react
```

```css
@import "@dimah-form/ui/styles.css";
```

Or copy the source with the shadcn CLI:

```bash
pnpm dlx shadcn@latest add https://form.dimah.dev/r/form.json
```

## FormView

```tsx
import { FormUiProvider, FormView } from "@dimah-form/ui";

const widgets = { rating: StarRatingField };

<FormUiProvider translations={fa} widgets={widgets}>
  <FormView form={form} />
</FormUiProvider>;
```

`layout="auto"` (the default) uses a wizard when `meta.step` spans more than one page, and `mode="review"` widgets when the response is locked.
Force one mode with `layout="fill" | "steps" | "review"` or `form.meta.layout`.

`FormReview` (a compact answer list) is opt-in: `review={<FormReview />}` or `components={{ Review: FormReview }}`.

Failed submit focuses the first invalid control. Enter on a non-last step advances instead of submitting.

### Slots

`header`, `progress`, `status`, `errorSummary`, `error`, `saveState`, `actions`, `stepList`, `stepHeading`, `stepNav`, `review`, `inactive`.

Pass `false` to hide, a node to replace, or a function to wrap the default:

```tsx
header={({ default: node }) => <Card>{node}</Card>}
```

The default header includes the save-state badge. A wizard shows `FormStepList` and omits the progress bar and step heading. `stepList={false}` restores the heading and step progress. `progress={<FormProgress variant="required" />}` keeps a completion bar in a wizard.

`render` replaces the composition. Keep `FormRoot` so Enter and submit still run:

```tsx
<FormView
  form={form}
  header={false}
  render={({ fields, actions, error, saveState }) => (
    <FormRoot>
      <Card>
        {fields}
        {error}
        {saveState}
        {actions}
      </Card>
    </FormRoot>
  )}
/>
```

Required labels use an asterisk. Replace it — or the whole frame — on the provider:

```tsx
<FormUiProvider
  components={{ RequiredMark, FieldFrame: MyFieldFrame }}
  formatIssue={(binding) =>
    binding.errorCode === "TOO_SMALL" ? "Pick a higher score" : undefined
  }
>
  <FormView form={form} />
</FormUiProvider>
```

Custom widgets should use `FormFieldFrame` so `components.FieldFrame` applies.

## Compose

`FormScope` provides the session. Children do not take a `form` prop:

```tsx
<FormScope form={form}>
  <FormRoot>
    <FormHeader />
    <FormProgress />
    <FormFields />
    <FormActions before={<CancelButton />} />
  </FormRoot>
</FormScope>
```

| Piece              |                                                                                                                                                                                                                                                                                    |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `FormField`        | `meta.widget` when it is registered and not a built-in `radio` / `switch` / `chips` variant, otherwise `field.type`. `children` replaces the widget. `mode` is `"edit"` or `"review"`                                                                                              |
| `FormFieldFrame`   | Label, description, help, issue. `layout` is `"stack"`, `"choice"`, or `"group"`. Sets `data-field-type`, `data-widget`, `data-required`, `data-invalid`                                                                                                                           |
| `FormFields`       | Maps `visibleFields`. `meta.section` groups into `FormSection` (`groupBy={false}` opts out). `meta.width` `"half"` / `"third"` shares a row                                                                                                                                        |
| `FormSteps`        | Groups `meta.step` (number or string, default `"1"`). Wrap **around** `FormRoot`. The current page is a key (`step`, `defaultStep`, `onStepChange`). Titles come from `form.meta.steps`. `FormStepNav` validates the step; the last step renders `children`, usually `FormActions` |
| `FormActions`      | Save, submit, and edit in a `ButtonGroup`. `save="auto"` hides Save when the session autosaves. `abandon` is opt-in. `sticky` pins the bar                                                                                                                                         |
| `FormProgress`     | Wizard page progress inside `FormSteps`, otherwise required-field completion                                                                                                                                                                                                       |
| `FormSaveState`    | Badge for dirty / saving / saved. Hidden while locked                                                                                                                                                                                                                              |
| `FormErrorSummary` | Links to invalid fields after validate or submit                                                                                                                                                                                                                                   |

Built-in widgets (`TextField`, `BooleanField`, …) work alone: `<EmailField binding={form.field("email")} />`.

A widget receives `{ binding, className, mode }` — not a spread binding.

## Definition meta

Type-check with `satisfies FormDefinitionUi`. Pass `FormDefinitionUi<typeof fieldTypes, typeof plugins>` when you have custom field types or plugin `$Meta`. Extra `meta` keys are allowed.

```ts
import { defineForm } from "@dimah-form/server";
import type { FormDefinitionUi } from "@dimah-form/ui/types";

export const onboarding = defineForm({
  title: "Onboarding",
  meta: { layout: "steps", steps: { "1": "About you", "2": "Work" } },
  fields: [
    {
      id: "name",
      type: "text",
      required: true,
      meta: { placeholder: "Ada", step: 1 },
    },
    {
      id: "role",
      type: "select",
      meta: { widget: "radio", step: 2 },
      options: [{ value: "eng", label: "Engineer" }],
    },
  ],
} satisfies FormDefinitionUi);
```

| Key                          | Effect                                                             |
| ---------------------------- | ------------------------------------------------------------------ |
| `multiline` / `rows`         | `text` renders a textarea                                          |
| `placeholder`                | Input or select placeholder                                        |
| `widget`                     | Registry key, or built-in `radio` / `switch` / `chips`             |
| `section`                    | Heading inside `FormFields`                                        |
| `step`                       | Page inside `FormSteps`                                            |
| `width`                      | `"half"` or `"third"`                                              |
| `prefix` / `suffix`          | `InputGroup` addon                                                 |
| `help`                       | Hint under the control                                             |
| `autocomplete` / `inputMode` | Forwarded to the input. `email` defaults `autoComplete` to `email` |
| `orientation`                | `FormFieldFrame` orientation                                       |
| `option.meta.description`    | Helper under a radio or checkbox option                            |
| `form.meta.layout`           | `auto`, `fill`, `steps`, or `review`                               |
| `form.meta.steps`            | Step key → heading                                                 |
| `form.meta.submitLabel`      | Submit button copy                                                 |
| `unsetOnOff`                 | Boolean **field** key, not meta. Off writes `null`                 |

For `saveForm` rows, pass a Zod object as `dimahForm({ metaSchema })`. Plugin `metaSchema` bags run first.

RTL uses logical CSS (`text-start`, `ms-*`, `ps-*`). Colors are `*-dimah-form-*` and follow your shadcn theme. Chrome roots set `data-slot` (`form-root`, `form-actions`, …).
