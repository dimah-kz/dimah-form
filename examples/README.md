# Examples

Workspace demos consume `@dimah-form/*` through `workspace:*`. Start with the
[Quickstart](https://form.dimah.dev/docs/quickstart) when integrating the
published packages into an application; use these examples to study a complete
workspace setup.

| Path              | Stack                                         |
| ----------------- | --------------------------------------------- |
| [`next/`](./next) | Next.js App Router, Drizzle RC, libSQL/SQLite |

The Next.js example combines durable persistence, the optional UI package, a
custom field type, scoring, dataset exports, and insights.
